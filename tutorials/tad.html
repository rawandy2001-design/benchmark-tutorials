Domain/TAD calling and reference-agreement tutorial¶

This public tutorial includes explanations, command examples and embedded figures. Command paths refer to the final_code3 analysis-code checkout. Scientific inputs and native software environments are configured separately.

This tutorial follows the completed Lee2019 L2-3, chr21, 25-kb example. Four callers are applied to three single-cell input conditions, giving 12 combinations. Their mean boundary scores are compared separately with three references called from the same raw pseudo-bulk matrix: 36 comparisons.

The example selects ten cells per input. Text and code blocks describe the existing implementation; opening this notebook does not run callers or load the input matrices.

Use the shared path setup for the commands below:

source tutorials/paths.sh
cd "${BENCHMARK_ROOT}/code"

from pathlib import Path
import os

BENCHMARK_ROOT = Path(os.environ["BENCHMARK_ROOT"])

The scHiCluster input selects the first ten biological IDs in L2-3.tsv. Higashi_0 selects the first ten original HDF5 cell keys in numeric order; Higashi_5 uses exactly those same keys. Within each input condition, all four callers receive the same selected cells.

The supplied HDF5 keys have no verified map to the separate Coolers' biological IDs. The example therefore records each selection explicitly without assuming cross-input identity from row position. Condition names retain the supplied filenames.

1.3. Prepare caller-specific formats¶

The main runner prepares the following adapters while retaining the original ZIP, HDF5, NPY, TSV and TXT inputs:

  1. Extract chr21 from the ten selected scHiCluster Coolers.
  2. Store selected HDF5 strict-upper vectors in temporary symmetric-upper Coolers for callers that read Cooler input. Original float values and coordinates are checked exactly after serialization.
  3. Supply Higashi with its native strict-upper HDF5 layout. For the scHiCluster branch, export off-diagonal Cooler values to that layout, recording adapter keys, biological IDs and the omitted source diagonal.

The adapters change the file representation. They do not re-impute, round, balance or rescale the stored imputed values.

Run just this stage from the repository root, using the TAD environment:

python tad/tool/run_tad_chr21_all12_example.py \
  --data-root "${BENCHMARK_ROOT}/data/higashi" \
  --output-dir "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example" \
  --max-cells 10 --cpu 4 --stage prepare

2. Domain calling and raw references¶

2.1. Call domains on each imputed cell¶

The combined runner dispatches the four callers with the following settings. The command examples illustrate one prepared input condition.

scHiCluster¶

hicluster domain --cell_table_path "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/tables/single_cell.tsv" --output_prefix "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/single_cell/scHiCluster/L2-3" --resolution 25000 --window_size 10 --cpu 4

It retains native TopDom insulation and boundary outputs for each cell.

Higashi¶

The Higashi workflow (tad/tool/higashi_callers.py in the code repository) uses the native sqrt_norm, insulation_score, call_tads and scTAD_calibrator routines. Insulation and TAD windows are 500 kb; seed 0 is recorded. The coverage mask uses the supplied raw sparse matrices, with native centromere masking and 1-Mb padding. Insulation, uncalibrated boundaries and calibrated boundaries are saved in the chromosome-specific scTAD.chr21.hdf5 output.

HiCExplorer¶

hicFindTADs --matrix "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/input/scHiCluster/cells/181218_snm3Cseq_hs_21yr_BA10_UMB5577_1_UMB5577_2_A10_AD001.chr21.25K.cool" --outPrefix "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/single_cell/HiCExplorer/181218_snm3Cseq_hs_21yr_BA10_UMB5577_1_UMB5577_2_A10_AD001/result" --minDepth 125000 --maxDepth 250000 --step 50000 --delta 0.01 --thresholdComparisons 0.01 --correctForMultipleTesting fdr

The native BEDGraph separation scores are aligned to genomic bins using the companion .bm file.

TADtool¶

${TAD_PYTHON} "${BENCHMARK_ROOT}/code/tad/tool/tadtool_di.py" --cell-table "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/tables/single_cell.tsv" --output-dir "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/single_cell/TADtool" --manifest-output "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/single_cell/TADtool/domains.tsv" --score-manifest-output "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example/result/scHiCluster/single_cell/TADtool/scores.tsv" --chromosome chr21 --num-workers 2 --window-size 250000 --cutoff 0.008

The adapter runs native directionality mode and reads its score from BED5 column 5. Caller commands and output hashes are retained by the implementation.

2.2. Call three references from raw pseudo-bulk¶

The same raw merged chr21 matrix is converted to the reference Cooler and called once with scHiCluster, HiCExplorer and TADtool. Their native settings are the same as those above. Positive boundary bins define three separate reference label tracks on the 25-kb grid.

raw-cell merged matrix
  ├── scHiCluster   → reference boundary labels
  ├── HiCExplorer   → reference boundary labels
  └── TADtool       → reference boundary labels

The three actual reference outputs are shared across all input conditions. They are retained under result/references/, with source commands and hashes. Higashi's internal calibration background is separate from these evaluation references.

3. Boundary scores and evaluation¶

3.1. Orient and average boundary scores¶

Each caller's continuous score is converted so that larger values represent stronger boundary evidence:

Caller Boundary score used for averaging
scHiCluster 1 − insulation
Higashi 1 − native insulation
HiCExplorer Negative native separation score
TADtool Absolute consecutive-bin directionality-index difference

For each combination, the resulting cell-by-bin values are averaged across the selected cells to obtain the mean boundary score. The implementation retains missing native scores and computes a common finite-bin mask across all twelve tracks.

The completed example evaluates 1,776 of 1,869 chr21 bins. Both the full tracks and the mask are written to the evaluation directory.

3.2. Evaluate reference agreement¶

Every mean score track is compared separately with the three raw reference label tracks. The calculations use:

from sklearn.metrics import roc_auc_score, average_precision_score

auroc = roc_auc_score(reference_labels[valid_bins], mean_score[valid_bins])
auprc = average_precision_score(
    reference_labels[valid_bins], mean_score[valid_bins]
)

Here, AUPRC denotes scikit-learn average precision. For each combination, the three AUROCs and three AP values are averaged separately. Individual reference comparisons are retained alongside the twelve mean summaries.

To combine already completed calls:

python tad/tool/run_tad_chr21_all12_example.py \
  --data-root "${BENCHMARK_ROOT}/data/higashi" \
  --output-dir "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example" \
  --max-cells 10 --stage evaluate

This entry also checks the prepared inputs before collecting native results.

3.3. Report per-cell domain counts¶

The example retains each caller's domain-count definition:

Caller Primary count
scHiCluster Native boundary endpoint multiplicity sum divided by two
Higashi Intervals between consecutive uncalibrated boundaries
HiCExplorer Native domain intervals
TADtool Native domain intervals

Higashi calibrated counts are saved separately. The primary table contains ten cell records for each of the twelve combinations. Counts accompany reference-agreement scores as a separate description of the outputs.

4. Run the example and inspect outputs¶

4.1. Run the complete example¶

Run inside WSL after selecting the software notes:

export PATH="$HOME/.venvs/schic-tad-example/bin:$PATH"
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1

python tad/tool/run_tad_chr21_all12_example.py \
  --data-root "${BENCHMARK_ROOT}/data/higashi" \
  --output-dir "${BENCHMARK_ROOT}/data/higashi/tad_chr21_all12_example" \
  --max-cells 10 --cpu 4 --stage all

The runner prepares adapters, calls missing native stages, builds the shared raw references and combines the results. Completed steps with matching records are reused. To select all available cells, use --max-cells 0 and a distinct output directory such as tad_chr21_all12_example_all_cells.

The generic batch notebook (tad/tool/tad_pipeline.py in the code repository) and its configuration (tad/tool/configs/tad_pipeline.json in the code repository) remain available for other datasets and chromosomes. The completed example above uses chr21 at 25 kb.
