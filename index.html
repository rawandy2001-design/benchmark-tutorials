2. Read the retained examples¶

Embedding retains the 42-cell Lee2019 example, all 22 autosomes at 100 kb, with its original saved score table and figure. Its fixed K-means groups are a separately recorded new demonstration; evaluation of original workflow assignments has its own section.

Domain/TAD retains the Lee2019 L2-3 chr21 example at 25 kb: ten cells per input, twelve caller/input combinations and thirty-six comparisons with the three shared raw pseudo-bulk references.

Loop follows the matched Mustache Raw/iEnhance example and describes the other caller branches and multimodal evaluations. Its ranking and figures section contains the saved summary panels. Compartment retains the original result notebook, including its Tan/Neuron settings and saved outputs, with hierarchical section headings.

3. Shared path setup¶

All tutorial commands use BENCHMARK_ROOT. The local workspace contains directory links to the existing code, inputs, software and saved records. The source files remain in their original locations.

Run this once from the code checkout in WSL:

source tutorials/paths.sh
cd "${BENCHMARK_ROOT}/code"

The local prefix is /mnt/f/project/test1/benchmark_workspace in WSL and F:/project/test1/benchmark_workspace in Windows. For a Windows Python session, set the corresponding environment variable in PowerShell:

$env:BENCHMARK_ROOT = "F:/project/test1/benchmark_workspace"

Python examples use:

from pathlib import Path
import os

BENCHMARK_ROOT = Path(os.environ["BENCHMARK_ROOT"])

The mappings and runtime settings are collected in paths.sh. On another machine, set its BENCHMARK_*_SOURCE values to the corresponding existing directories. Original file excerpts retain the paths recorded in their source files.
